# Тестовое задание — Web-интерфейс администрирования пользователей

Простой PHP+MySQL проект без использования фреймворков. Реализует
CRUD для таблицы зарегистрированных пользователей сайта, доступный
только после аутентификации администратора.

## Технологии

- PHP 8.4
- MySQL 8.4
- Apache (mod_rewrite обязателен — см. ниже)

## Установка

1. Скопируйте содержимое проекта в директорию вашего локального
   сервера (например, для OpenServer — в `domains/ваш-домен/`).

2. Убедитесь, что **DocumentRoot указывает на папку `public/`**
   внутри проекта, либо, если это невозможно настроить напрямую —
   в корне проекта уже лежит `.htaccess`, который перенаправляет
   все запросы в `public/`. Для его работы на Apache обязательно
   должен быть включён модуль **`mod_rewrite`**.

3. Создайте базу данных в MySQL (например `sibers_db`) и
   импортируйте прилагаемый дамп `sibers_db.sql` (Экспорт/Импорт через
   phpMyAdmin, либо `mysql -u root -p sibers_db < sibers_db.sql`).
   Дамп содержит структуру таблиц `users`/`admins` и тестовые
   записи.

4. Откройте `config.php` в корне проекта и пропишите свои данные
   для подключения к БД:

   ```php
   $host     = "127.0.1.31";   // хост MySQL — для OpenServer обычно
                                 // выглядит как 127.0.1.x, для других
                                 // окружений чаще localhost/127.0.0.1
   $db_name  = "sibers_db";
   $username = "root";
   $password = "";
   ```

5. Откройте сайт в браузере — вы будете перенаправлены на страницу
   входа.

## Тестовые данные для входа

Для проверки функциональности используйте:

- **Логин:** `siber_admin`
- **Пароль:** `123`

(эти данные соответствуют записи в таблице `admins` из дампа
`sibers_db.sql`)

## Структура проекта

```
public/            — единственная папка, доступная веб-серверу
  index.php         — точка входа, роутинг
  .htaccess         — перенаправление запросов в index.php
  css/               — стили
Controllers/         — обработка запросов
Model/                — работа с базой данных (PDO)
Database/            — подключение к БД (Singleton)
View/                 — HTML-шаблоны
config.php           — данные подключения к БД
dump.sql             — SQL-дамп базы (структура + тестовые данные)
```

## Функциональность

- Список зарегистрированных пользователей (пагинация, поиск по логину)
- Просмотр карточки пользователя
- Добавление / редактирование / удаление пользователя
- Аутентификация администратора (сессии), доступ к панели закрыт
  для неавторизованных пользователей
